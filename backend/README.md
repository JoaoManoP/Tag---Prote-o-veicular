# Backend

Esta pasta concentra a aplicacao do servidor e seus testes.

- `server/`: API Express, autenticacao, Socket.IO, provedores e regras de negocio.
- `tests/`: testes automatizados do servidor, da integracao e dos contratos do frontend.

O ponto de entrada e `backend/server/server.js` e pode ser iniciado na raiz com `npm start`.
