# STACK: REACT NATIVE

- Não considerar o aplicativo compilado um ambiente secreto.
- Não incluir chaves privadas ou credenciais permanentes no bundle.
- Usar armazenamento seguro para tokens quando aplicável.
- Validar deep links e dados recebidos de outras aplicações.
- Minimizar logs sensíveis.
- Aplicar autorização no backend.
- Considerar permissões do dispositivo, dados locais e comunicação segura.
- Tratar engenharia reversa como risco esperado.
