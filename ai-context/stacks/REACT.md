# STACK: REACT

- O frontend não é uma barreira de segurança.
- Não inserir segredos no bundle.
- Não usar controle visual como substituto de autorização no backend.
- Tratar dados externos como não confiáveis.
- Evitar renderização de HTML não sanitizado.
- Usar validação de formulário para experiência do usuário, mantendo validação no backend.
- Não confiar em campos ocultos ou estado local para proteger operações.
- Tratar loading, erro, estados vazios e ausência de permissão.
- Evitar exposição desnecessária de dados no estado, logs ou ferramentas de depuração.
