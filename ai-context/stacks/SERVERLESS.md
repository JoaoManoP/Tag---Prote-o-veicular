# STACK: SERVERLESS

- Validar cada evento recebido.
- Aplicar autenticação e autorização em cada função sensível.
- Usar permissões mínimas para execução e acesso a recursos.
- Controlar timeout, retries, concorrência e idempotência.
- Evitar credenciais permanentes.
- Gerenciar conexões com banco de forma compatível com o ambiente.
- Não confiar exclusivamente no gateway como controle de segurança.
- Isolar dados e recursos por tenant quando aplicável.
