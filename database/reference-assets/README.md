# Ativos de referência

Esta pasta guarda as referências visuais aprovadas para impedir que futuras alterações ou publicações removam a identidade das telas.

- `images/`: mapa-base e logotipo usados como referência visual.
- `videos/`: vídeo definitivo da home, mantido também fora do diretório público.
- `screenshots/`: capturas validadas das telas implementadas em desktop e celular.
- `specs/`: regras de composição e elementos obrigatórios de cada tela.

Os arquivos desta pasta são referências versionadas. As capturas usam estados vazios ou dados reais e nunca devem introduzir veículos, viagens, ocorrências ou pessoas fictícias no site.
