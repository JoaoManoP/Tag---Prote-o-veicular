# Vídeo do hero

Adicione aqui o vídeo cinematográfico final, sem textos ou elementos de interface:

- `rastreon-hero-motion.webm` (preferencial)
- `rastreon-hero-motion.mp4` (fallback)

Enquanto nenhum desses arquivos existir, a home mantém automaticamente a imagem estática atual. Os vídeos de referência recebidos não são usados como mídia de produção.
